# Security policy

## Escopo
Skills são instruções e podem conter scripts executáveis. Revise o SKILL.md, arquivos de referência e scripts antes de instalar. Este projeto não solicita tokens, credenciais, passwords ou dados privados.

## Tratamento de dados acadêmicos
Não inclua dados pessoais de participantes, material sob sigilo de pesquisa, credenciais vazadas ou bases sem autorização em issues públicas. Prefira exemplos sintéticos e arquivos reduzidos.

## Reporte
Para uma falha de segurança, evite publicar o exploit ou dados sensíveis em issues. Use canais privados oferecidos pelo GitHub caso estejam habilitados no repositório; caso contrário, solicite ao mantenedor um canal privado antes de compartilhar detalhes.

## Limitações
A skill não realiza auditoria automática de veracidade. Nunca considere conteúdo gerado por IA como prova científica sem verificação independente.
